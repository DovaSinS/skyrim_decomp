# Claude entry point

@AGENTS.md

For an external contributor, start with [the contributor guide](docs/contributing-agent.md) and
[contributor card](docs/contributor-card.md). Follow AGENTS.md's common privacy/evidence rules;
do not import the internal pipeline's runner, queue or role workflow into a contributor clone.

Internal project workers must additionally read [the internal workflow](docs/internal-agent-workflow.md).
If imports are unsupported, open AGENTS.md explicitly. Do not inherit Mudcrab instructions.
